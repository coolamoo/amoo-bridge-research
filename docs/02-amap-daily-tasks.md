# 02 · 高德达人日常任务路径

以「我的 → 更多任务 → 任务中心」为主线。设备 1200×2670，坐标均为**截图上量出来的真实触控点**。

## 通用前置：把前台抢回来

高德经常不在前台（要么被聊天抢走，要么停在悬浮小窗里）。
每条链都以 `launch` 开头，必要时补一次 `back` 退出小游戏页：

```
launch com.autonavi.minimap (5000)
back                          # 若恢复到大富翁游戏页
```

## 答题任务

### 入口路径

```
底部「我的」         (969,1978)
上滑一屏              (600,1800) → (600,700)
再上滑一屏            (600,1600) → (600,900)
「更多任务」          (581,657)
任务中心里 90 天答题行右侧「去完成」
```

任务中心那一行在整屏约 y=1150，右侧「去完成」按钮中心 ≈ **(875,1150)**。
注意卡片上方还有别的「去完成」（关注探店达人等），**按 y 区分，不要按文本匹配**。

### 答题页

点进去是「我的反馈 / 共建问答」半屏页，首屏是一张卡片：

```
地点名
地址
「这个地点还存在吗？」   → 存在 / 不存在 / 不知道
「这个地点是在1层吗？」  → 在这层 / 不在这层 / 不知道
「这里最近正常营业吗？」 → 正常营业 / 未营业 / 不知道
```

选项按钮的真实纵坐标约 **y=1555~1580**，三个按钮横向约 x=235 / 500 / 790。

### 判定标准（重点）

- **正向选项任选其一就能完成当天答题**：`在这层` / `存在` / `正常营业` 都算数；
- 题目本身不必答「对」，地址信息不全也不用纠结；
- **提交成功的信号**：第一张卡换成下一题（原卡片消失、新地点出现在顶部）；
- **最终判定**：退回任务中心刷新，看「最近130天内累计完成90天答题」的天数。

实测记录：

| 日期 | 答前 | 答后 |
|---|---|---|
| 11-23 | 36 | 37 |
| 11-26 | 35 | 36（当日第二次答题又到 37）|
| 11-27 | 37 | 38 |

### 任务周期机制（官方规则，2026-11-28 确认）

任务卡上写的规则原文：

1. 任务周期为最近的 130 天，**周期每日更新**，即以当前日期为终点，向前追溯 130 天（含当天）
2. 需在周期内累计完成 90 天打卡
3. **任务进度更新有延迟**，请耐心等待

这三条解释了为什么「答了但数字不动」：

- 这是一个**滚动窗口**。每过一天，窗口右移一天：最老的一天滑出，今天滑进来。
- 总数 = 窗口内的打卡天数。所以每天的实际变化是：
  - 滑出的那天**打过卡** → 今天也打卡 → 净变化 **0**（看起来「没涨」）
  - 滑出的那天**没打卡** → 今天打卡 → **+1**
- 也就是说，数字不涨不代表没生效，而是被窗口另一端抵消了。
- 另外进度是**异步更新**的，答完立刻刷新可能还是旧值。

**正确的心态**：每天固定答一次，不要去追当天的数字。
只有连续多天数字都不动，才需要怀疑是不是真的没计上。

历史实测（与滚动窗口模型吻合）：

| 日期 | 答前 | 答后 |
|---|---|---|
| 11-23 | 36 | 37 |
| 11-26 | 35 | 36 → 37（同日两次） |
| 11-27 | 37 | 38 |
| 11-28 | 38 | 38（当天两次，均提示「感谢您的参与」） |

11-28 这天两次都提交成功却都是 38，正是「滑出日也是打卡日」导致的抵消，不是提交失败。

## 地图大富翁

### 进入

```
首页搜索框         (600,1263)   # 节点 id: txt_hotword，文本「查找地点、公交、地铁」
输入「地图大富翁」
点「搜索」         (880,384)
```

搜完会自动跳到游戏页（H5 画布，控件树基本是空的）。

### 游戏内

- 底部橙色圆形「前进」按钮 ≈ **(600,1830)**，点一次掷一次骰子，金币会涨；
- 顶部 `3/3` 是资源计数，不一定是骰子；
- 「前进」下方 `xx/15` 是进度数字，会随掷骰变化；
- 地图上的宝箱 ≈ **(868,1768)**，点它出提示条；
- 左下「回小镇」按钮在宝箱所在地图页的左下角。

### 干扰项

- 掷骰过程中会弹「翻身机会 · 猜大小」赌注面板（有「猜小/确认/猜大」），
  不属于日常任务，按 `back` 关掉即可，不要去押注；
- 会弹「每日抽奖」（恭喜获得 +5 骰子之类），同样按 `back` 关掉。

## 不要做的事

- 不要用 `do tap by=text 去完成` ——任务中心里同名按钮有 4 个，点到哪个不由你决定；
- 不要用 `do tap by=text 我的` ——找不到时会退化成 OCR，而首页广告区的 OCR 是乱码；
- 不要在答题页用树坐标点选项 ——会差 570 px，点空。
